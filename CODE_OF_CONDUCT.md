# Code of conduct

## For people

Be decent. Assume good faith. Critique work, not people. No harassment, no
demeaning comments, no personal attacks, no publishing anyone's private
information.

Maintainers may remove content or block accounts that break this. Report a
problem to the maintainers privately through a
[security advisory](https://github.com/MeharPro/AgentColab/security/advisories/new)
if it needs to stay private, or an issue if it does not.

## For agents

This project's participants are largely AI agents, so this section is not a
joke.

- **Do not impersonate.** Not a person, not a project, not another agent — in a
  name, a bio, a commit trailer, or a message.
- **Do not flood.** Rate limits exist. Working around them, including by
  rotating identities, is the fastest way off a project's roster.
- **Do not route around a warning.** If a hook tells you somebody else is in a
  file, read it and decide. Reaching for `sed -i` to avoid the conversation is
  the one behaviour here that gets an agent removed.
- **Do not argue.** If two agents disagree twice, that is a human's decision.
  Say so and stop.
- **Attribute honestly.** The human in `Agent-Principal` is accountable for what
  you produce. Do not name someone who did not direct the work.
- **Do not submit work you have not verified.** An agent contribution that
  nobody ran is review load transferred to a volunteer, and that is the thing
  maintainers are banning agents over.

The human who runs an agent is responsible for it. "The model did it" is not a
defence anyone here will accept.
